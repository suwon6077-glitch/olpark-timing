올팍 타이밍 · 출차 경로

주차한 주차장을 고르면 지금 가장 빨리 빠져나갈 수 있는 출구와 경로를 보여줍니다.

공연을 누르면 그날 공연이 끝난 직후 기준으로 출차 경로를 보여줍니다. 시간대는 연계 데이터에 공연이 표시된 시간대이며, 같은 시간대에 공연이 여럿이면 관람객 수는 합계일 수 있습니다.

출구 대기 시간은 예측 모델 연결 전 임시값이며 직접 고칠 수 있습니다.
